# Attribution and scope

The original Online Retail dataset is Daqing Chen (2015), UCI Machine Learning Repository, DOI 10.24432/C5BW33, licensed CC BY 4.0: https://creativecommons.org/licenses/by/4.0/.

The source workbook is preserved unchanged in the downloadable handoff. Source data, SQLite databases and processed row-level exports are excluded from Git tracking. Their download/rebuild instructions, original SHA-256 and data-quality counts are supplied.

Original project implementation code is licensed separately under MIT. The Excel file contains derived aggregates and anonymized customer identifiers from the credited dataset. Simulated business roles and recommendations do not represent paid stakeholder work, client engagement or measured business outcomes.
